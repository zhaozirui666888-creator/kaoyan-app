# 考研作息网页第五版

这是基于第四版继续升级的本地离线 PWA 网页。

## 使用
1. 解压 ZIP。
2. 双击 `index.html` 即可在浏览器使用大部分功能。
3. 若希望安装成 PWA，建议通过本地静态服务器打开（例如 VS Code Live Server），再使用浏览器的“添加到主屏幕/安装”。
4. 数据默认保存在浏览器本机 localStorage，不需要账号。

## 本版重点
- 04:00 考研日边界；周一 04:00 为周边界；每月1日 04:00 为月边界的统计设计。
- “计入考研任务”开关。
- 任务完成：实际时长 + 必选 1–5 星；支持超过4小时自定义。
- 计划/实际时长对比与超额显示。
- 休息日、周模板、延用上周模板。
- 日/周/月数据中心、科目时长饼图、任务日期钻取、实际时长柱状图。
- 每日心得自动保存、手动保存反馈、日/周心得便签墙。
- 日历选择、左右箭头/触摸滑动、浅色/深色/跟随系统。
- iOS 风格底部 Sheet 与过渡动画。
